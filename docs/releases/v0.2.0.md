Rhino ERP is a desktop app for offline **ERP analysis** of EEG recordings (BDF/EDF) from [Rhino Recorder](https://github.com/itubrainlab/rhinorecorder) and the g.tec **Unicorn Hybrid Black**, on Windows, macOS and Linux. All processing is done with [MNE](https://mne.tools).

## New in 0.2.0: independent component analysis (ICA)

![ICA tab](https://raw.githubusercontent.com/itubrainlab/rhinoerp/v0.2.0/docs/screenshot-ica.png)

A new, optional **ICA** step removes artifacts such as eye blinks from the EEG without an EOG channel.

- **Fit**: extended Infomax on the filtered EEG channels, fitted on the data from the first to the last trigger and applied to the whole recording. The number of components defaults to the rank of the data and can be lowered.
- **Inspect**: the new *ICA* tab shows every component with the panels of MNE's `plot_properties`, drawn as charts in the app: scalp map, image of the recording in 2-s segments with their average, spectrum, and the variance of each segment.
- **Label**: each component gets a suggested label from MNE's detectors on the EEG alone: *Eye blink* when it correlates with the most anterior electrode (`find_bads_eog`, with Fz standing in for an EOG channel), *Muscle (EMG)* from `find_bads_muscle`, otherwise *EEG*. Labels can be changed, and *Line noise*, *Channel noise* or *Other* set by hand.
- **Reconstruct**: components labelled as artifacts start unticked. *Reconstruct from selected* rebuilds the EEG from the ticked components only; *Undo* goes back. The *Signals* tab shows the cleaned data.
- **Export**: the exported MNE script loads the fitted ICA (saved next to it) and removes the same components, with their labels listed in the settings.

## Other changes

- **Processing order**: channels → filtering → trigger and events → ICA → reference → epochs. The reference now has its own step, applied after ICA; computed ERPs update when it changes.
- **MNE throughout**: filtering (zero-phase IIR Butterworth), event detection, the EEG delay, channel means, GFP and peaks now use MNE functions. The app no longer filters with g.Pype, and the exported script repeats the app's analysis exactly.
- **Statistics**: the window mean amplitude is compared with a two-sided Welch t-test, reported with its degrees of freedom and p-value (from SciPy, as MNE has no Welch p-value). The permutation test, Hedges' g and the jackknife latency test have been removed; peak amplitudes, latencies and their difference are still reported.

## Downloads

| | File |
|---|---|
| Windows 10 or 11, 64-bit | `RhinoERP-0.2.0-windows-x86_64.zip` |
| macOS, Apple Silicon (macOS 12+) | `RhinoERP-0.2.0-arm64.dmg` |
| Linux, x86_64 (glibc 2.34+: Ubuntu 22.04, Debian 12, Fedora 35 or later) | `RhinoERP-0.2.0-linux-x86_64.tar.gz` |

`SHA256SUMS` lists the checksums.

**First launch needs an internet connection.** The packages contain their own Python and Rhino ERP, but not g.Pype, which provides the app's theme: the g.tec Non-Commercial License does not allow g.Pype to be redistributed in a bundle. On first launch the app downloads g.Pype, MNE and the other libraries from PyPI (several hundred MB, a few minutes), at the versions this release was tested with. Later launches start directly.

### Windows
Unpack the zip and double-click **install.cmd**, then open Rhino ERP from the Start menu.

### macOS
Open the DMG and drag **Rhino ERP** to Applications. The app is not notarized by Apple, so the first time, right-click it and choose **Open**.

### Linux
Unpack the tarball and run `./install.sh`, then open Rhino ERP from the applications menu or run `rhino-erp`.
