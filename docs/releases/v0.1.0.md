Rhino ERP is a desktop app for offline **ERP analysis** of EEG recordings (BDF/EDF) from [Rhino Recorder](https://github.com/itubrainlab/rhinorecorder) and the g.tec **Unicorn Hybrid Black**, on Windows, macOS and Linux. It uses [MNE](https://mne.tools) and [g.Pype](https://gpype.gtec.at).

## What's in 0.1.0
- **Channels and electrodes**: the first 8 channels start as EEG with the Unicorn Hybrid Black electrodes (Fz, C3, Cz, C4, Pz, PO7, Oz, PO8); any channel can be selected, typed and given a 10-05 electrode label.
- **Reference (optional) and filtering**: average, one or two reference channels; high-pass, low-pass and line-noise notch as zero-phase Butterworth filters run through g.Pype.
- **Trigger and events**: any channel can be the trigger channel (e.g. `TRIG`, BioSemi `Status`) or the file's annotations; codes are named, pooled and preselected.
- **EEG delay**: a slider that compensates a recording delay between triggers and EEG, with ERPs and statistics updating live.
- **Epochs and ERPs**: single channel, channel mean, GFP and butterfly views, topographic maps at any latency, rejection report, `-ave.fif` export.
- **Statistics**: compare two conditions on a preset (P1, N1, N170, P2, N2, MMN, P300, N400, LPP) or custom component: window mean amplitude with Welch t-test, permutation test and Hedges' g; peak amplitude and latency with a jackknife latency test; CSV export.
- **Export as MNE script**: a short, commented MNE script that reproduces the analysis, with topographic maps and the statistics graph.

## Downloads

| | File |
|---|---|
| Windows 10 or 11, 64-bit | `RhinoERP-0.1.0-windows-x86_64.zip` |
| macOS, Apple Silicon (macOS 12+) | `RhinoERP-0.1.0-arm64.dmg` |
| Linux, x86_64 (glibc 2.34+: Ubuntu 22.04, Debian 12, Fedora 35 or later) | `RhinoERP-0.1.0-linux-x86_64.tar.gz` |

`SHA256SUMS` lists the checksums.

**First launch needs an internet connection.** The packages contain their own Python and Rhino ERP, but not g.Pype: the g.tec Non-Commercial License does not allow g.Pype to be redistributed in a bundle. On first launch the app downloads g.Pype, MNE and the other libraries from PyPI (several hundred MB, a few minutes), at the versions this release was tested with. Later launches start directly.

### Windows
Unpack the zip and double-click **install.cmd**, then open Rhino ERP from the Start menu.

### macOS
Open the DMG and drag **Rhino ERP** to Applications. The app is not notarized by Apple, so the first time, right-click it and choose **Open**.

### Linux
Unpack the tarball and run `./install.sh`, then open Rhino ERP from the applications menu or run `rhino-erp`.
